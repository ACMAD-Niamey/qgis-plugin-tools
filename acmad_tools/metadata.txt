description=A growing toolbox of QGIS plugins for ACMAD backend workflows. Currently includes drought forecast polygon shapefile ingestion, with more tools to be added over time.
about=A small, extensible toolbox plugin: each tool lives in its own subpackage and shares a common toolbar/menu and backend connection settings. The first tool lets a domain expert pick a seasonal drought forecast shapefile (.shp/.shx/.dbf/.prj) from disk, fill in the forecast metadata (period, lead name, date produced, year), and upload it in one click to the ACMAD Drought Advisory backend's forecast ingestion endpoint. The shapefile parts are zipped client-side and posted as multipart/form-data over Qt's own network stack, authenticated with a pre-issued DRF API token stored in QGIS settings. No self-service login: tokens are obtained out-of-band from a backend administrator.
